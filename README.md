# Projeto Boné Código Fonte

Estrutura do projeto:

- `index.php` — sessão PHP e controle do estoque.
- `esgotado.html` — página exibida quando o estoque acaba.
- `obrigado.html` — confirmação da compra.
- `css/style.css` — estilos externos.
- `js/script.js` — JavaScript externo.
- `identificacao.txt` — RA e nome.

O estoque é armazenado na variável de sessão `$_SESSION['estoque']` e utilizado pelo PHP na página.
